### Added
- `@letdraw/mcp` — zero-config stdio bridge to the hosted MCP server.
- `@letdraw/sdk` — typed REST client for the public API.
- API spec (`spec/openapi.yaml`), tool reference (`spec/mcp-tools.md`), and the
  drawing capabilities guide (`spec/capabilities.md`).
- Client setup docs for Claude Desktop, Claude Code, Cursor, VS Code and Codex.
- Example recipes: from-code, generate-from-prompt, stamp-icons, export.
